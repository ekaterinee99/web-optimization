# Project Proposal — BookNest

## Idea
BookNest is a simple book discovery website where readers can browse a small collection, search for titles or authors, filter by genre, and save favourites.

## Target audience
Readers, students and people looking for a new book.

## Main sections
- Home introduction
- Book collection with search and filters
- About BookNest
- Contact form
- Footer

## Technologies
HTML5, CSS3, vanilla JavaScript, Git and GitHub.

## Planned work
1. Create the page structure.
2. Style the site for desktop and mobile.
3. Add search and genre filtering.
4. Add favourites using localStorage.
5. Validate the contact form.
6. Test in two browsers, check responsive layouts, optimize and document the project.

## Limitations
The catalogue uses sample data. The contact form is a front-end demonstration and does not send messages. Browser testing and Lighthouse measurements should be completed before submission.
